# Contributing

NatDD 0.x is open for public review. Please submit proposed changes as GitHub issues or pull requests.

Every proposed term change should state:

1. the business requirement;
2. why an established vocabulary does not already cover it;
3. the proposed class or property IRI and definition;
4. expected subject and object types;
5. at least one RDF example;
6. migration effects for existing NatDD data.

Terms must not be added merely as aliases for RDF, RDFS, OWL, DCAT, Dublin Core, SKOS, PROV-O or QUDT terms.
