# Changelog

## Unreleased

- Removed the geographic qualifier from current National Data Dictionary descriptions.

## 0.1.0 — 2026-08-26

Initial Public Review Draft.

- Defines the NatDD core classes and structural predicates used by SchemaForge publications.
- Reuses standard vocabularies for generic metadata, provenance, mappings, units, labels and value lists.
- Documents the provisional KBOB-scoped namespace and future migration policy.
- Excludes ConceptUsage, IDS extensions and SHACL application profiles from the release.
- Documents the `DocumentType` and `TaxonomyNode` roles used by the KBOB document-type taxonomy.
- Retains `AllowedValue` as a deprecated compatibility class and documents `documentItemReference`.
